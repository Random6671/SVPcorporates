# SVP Corporates — MIHAN

Standalone single-page website for SVP Corporates at Anjani Exotica, MIHAN, Khapri, Nagpur.

## Files
- `index.html` — the complete website
- `assets/` — property photography, the SVP logo, and Airbnb icons used on the page (only files actually referenced by `index.html` are kept here)

## Open it
Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

then visit `http://localhost:8080/index.html`. The property photography and logos are fully local; only the Google-hosted webfonts and the embedded Airbnb listing widget require an internet connection.
